A personal habit planner (closer to a quest tracker than a journal) that turns a physical pegboard into an interactive **8-bit** web app: daily main/side quests, a stage map, and photo hotspots mapped onto the real board.

## Product intent

Keep the ritual of the physical board, but make progress legible over time — stage clears, coin/score from side quests, and a photo diary where each magnet can hold a note or sub-photo.

## Tech stack (MVP)

- **Frontend:** Next.js (React) or plain HTML/Vanilla JS, whichever stays lightest for MVP
- **UI:** NES.css (8-bit Mario/Kirby feel) + layout CSS
- **Storage:** `localStorage` with a JSON shape that can migrate to a DB later

## Core features

### A. Stage & progress (8-bit map)

**Main Quests** (required to advance the stage that day):

1. Exercise
2. Data analysis / SQL study
3. Apply to at least one Operations Analyst (or similar) role

**Side Quests** (bonus coins/score): laundry, cleaning, reading, etc.

When all three Main Quests are done for the day, the character moves to the next stage on a 2D map. Side Quests only add score/coins.

### B. Daily photo + hotspot mapping

- Upload a photo of that day’s physical pegboard
- Click magnet/sticker positions to create hotspots (`x_percent`, `y_percent`)
- Persist image data (Base64 or object URL) with the hotspot array for that date

### C. Photo diary & modal

- Gallery/calendar grid of past days
- Open a day → full photo with absolute-positioned hotspot markers
- Click a hotspot → note text and optional sub-photo for that quest/magnet

## Data shape (JSON)

```json
{
  "date": "2026-07-28",
  "mainQuests": { "exercise": true, "study": true, "jobApply": true },
  "sideQuests": { "laundry": false, "reading": true },
  "mainPhoto": "data:image/jpeg;base64,...",
  "hotspots": [
    {
      "id": "hs_1",
      "x_percent": 45.2,
      "y_percent": 30.5,
      "note": "Finished SQL query optimization",
      "subPhoto": null
    }
  ]
}
```
