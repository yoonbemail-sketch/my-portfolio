Where should idle elevators wait in an **apartment**? This tick-based simulator holds the passenger scenario fixed (seeded arrivals), then compares parking strategies so only elevator policy changes.

## Fair comparison

1. Traffic inputs + **scenario seed** define one passenger stream
2. **Replay** restarts the same stream
3. **Compare all** runs every parking strategy headlessly on that stream
4. Change seed / New only when you want a different world

## Question

“배치” means **where to send a free car while it waits**. With identical arrivals, lobby parking vs stay/spread differences show up cleanly in avg wait and empty travel.

## Traffic model (apartment default)

| Period | Typical flow |
| --- | --- |
| Morning egress | Upper floors → lobby |
| Evening ingress | Lobby → upper floors |
| Midday / off-peak | Both directions |

Interfloor trips default to **10%**. Office any-floor OD is deferred.

## Controls

| Control | Role |
| --- | --- |
| Parking strategy | Stay / Lobby / Mid / Spread / Demand |
| Scenario seed | Fixed passenger stream |
| Traffic period | Morning / Evening / Midday |
| Interfloor % / Door dwell | Residential OD / stop time |
| Building knobs | Floors, cars, capacity, arrival rate |

## Metrics

- **Avg / Max wait** — hall call to board
- **Empty travel** — floors moved empty (parking cost)
- **Ticks / Completed** — makespan and throughput
