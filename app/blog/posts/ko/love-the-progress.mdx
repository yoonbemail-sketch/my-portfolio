일기보다 **플래너/퀘스트 트래커**에 가까운 개인 습관 앱입니다. 실물 페그보드를 **8비트** 웹으로 옮겨, 하루 Main/Side Quest·스테이지 맵·보드 사진 위 핫스팟을 남깁니다.

## Product intent

보드의 루틴은 유지하되, 진행이 시간에 따라 보이게 합니다. 스테이지 클리어, Side Quest 코인/점수, 자석마다 메모·서브사진을 붙일 수 있는 포토 다이어리.

## Tech stack (MVP)

- **Frontend:** Next.js (React) 또는 가벼운 MVP용 HTML/Vanilla JS
- **UI:** NES.css (8비트 마리오/커비 톤) + 레이아웃 CSS
- **Storage:** `localStorage` + 이후 DB 이전이 쉬운 JSON 구조

## Core features

### A. Stage & progress (8-bit map)

**Main Quests** (당일 스테이지 진행 조건):

1. 운동
2. 데이터 분석 / SQL 공부
3. Operations Analyst 등 직무 1개 이상 지원

**Side Quests** (보너스 코인/점수): 빨래, 청소, 독서 등.

Main Quest 3개를 모두 완료하면 2D 맵에서 캐릭터가 다음 스테이지로 이동합니다. Side Quest는 점수/코인만 쌓습니다.

### B. Daily photo + hotspot mapping

- 그날 실물 페그보드 사진 업로드
- 자석/스티커 위치를 클릭해 핫스팟 생성 (`x_percent`, `y_percent`)
- 이미지(Base64 또는 object URL)와 해당 날짜의 핫스팟 배열을 함께 저장

### C. Photo diary & modal

- 과거 기록 갤러리/캘린더 그리드
- 날짜 클릭 → 사진 위 absolute 핫스팟 마커
- 핫스팟 클릭 → 텍스트 메모 및 선택적 서브사진

## Data shape (JSON)

```json
{
  "date": "2026-07-28",
  "mainQuests": { "exercise": true, "study": true, "jobApply": true },
  "sideQuests": { "laundry": false, "reading": true },
  "mainPhoto": "data:image/jpeg;base64,...",
  "hotspots": [
    {
      "id": "hs_1",
      "x_percent": 45.2,
      "y_percent": 30.5,
      "note": "SQL 쿼리 최적화 완료",
      "subPhoto": null
    }
  ]
}
```
