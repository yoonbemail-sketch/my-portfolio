## Operational question

반복적인 ATS 지원을 어떻게 줄이되, 검수 없는 자동 제출과 채용 URL을 외부 서비스에 붙여넣는 방식은 피할 수 있을까?

이 프로젝트는 로컬 Streamlit 도구입니다. 사용자가 선택한 Chrome 탭에 연결하고, 직무 설명에 맞춰 맞춤 이력서 버전을 순위한 뒤, 비공개 resume hub의 데이터로 인식된 폼 필드를 채웁니다. 최종 제출은 지원자가 수행합니다.

## Method

```text
Active Job Tab ──> JD Extractor ──> Matcher ──> Structured Gap Analysis
                                         ^
                                         |
                                  Resume Data Hub
                                         |
                                         v
Active ATS Tab ──> Soft ATS Hint ──> Catalog / Adapters ──> Reviewed Form Fill
```

Streamlit UI는 **Analyze → Apply → Autofill** 순서를 따릅니다. 매칭은 기본적으로 결정론적입니다. 지원 가능 여부를 먼저 평가한 뒤 이력서 버전을 순위화하며, LLM 경로는 `MATCH_USE_LLM=1`로 선택합니다. Autofill은 soft ATS 감지와 공유 필드 카탈로그를 결합합니다(Workday, Greenhouse, SuccessFactors, Dayforce, Phenom, Jobvite, Oracle Cloud 등). 경력·학력 어댑터는 Workday, Phenom, Dayforce 페이지 형태를 대상으로 합니다.

### Zero-URL contract

Playwright는 CDP로 사용자가 관리하는 Chrome에 연결하며, 명시적으로 선택한 탭에서만 동작합니다. UI는 채용 URL이나 직무 설명 텍스트 붙여넣기를 받지 않습니다. 탐색, 인증, 제출은 지원자가 통제합니다.

### Operating constraints

1. **자동 제출 없음** — 사용자의 명시적 동작 없이 지원서를 게시하지 않습니다
2. **채움 결과 공개** — 매핑된 필드와 수동 입력이 필요한 필드를 보고합니다
3. **큐레이션된 프로필 보존** — hub 프로필 값을 오래된 import 문구로 덮어쓰지 않습니다
4. **Soft ATS 감지** — 알 수 없는 호스트에도 카탈로그 채움을 시도할 수 있으며, Submit은 클릭하지 않습니다

## Status

로컬 파이프라인은 구현되어 있으며 GitHub에 문서화되어 있습니다. 데모 GIF와 필드 단위 검증 표(ATS × 채움 필드 × 실패 모드)는 추후 공개 예정입니다.

## Limitations

- 검수 없는 전 구간 자동 제출은 범위 밖입니다
- ATS 커버리지는 부분적이며 DOM signature에 의존합니다. 새 포털에는 카탈로그 또는 어댑터 작업이 필요합니다
- 추천 라벨(`APPLY` / `APPLY_WITH_CAUTION` / `DO_NOT_APPLY` / `NEEDS_REVIEW`)의 공개 정확도 샘플은 아직 없습니다
- 비공개 resume hub는 로컬에 유지되며, 이 글에는 개인 데이터를 포함하지 않습니다

## Tech stack

Python · Streamlit · Playwright (CDP) · Pydantic · BeautifulSoup · pypdf / python-docx · 선택적 Gemini / Anthropic / OpenAI

## Design notes

- 지원자 기본 데이터와 플랫폼 DOM 세부사항·선택적 모델 호출을 분리합니다
- 매칭 결과는 Pydantic으로 검증하고, 기본 경로는 결정론적으로 유지합니다
- 쉽게 낡는 이력서 문구 하드코딩보다 importer 기반 갱신을 우선합니다
- 로컬 DOM signature 기반 ATS 감지는 힌트로 쓰고, 유료 URL 분류기를 전제로 하지 않습니다
