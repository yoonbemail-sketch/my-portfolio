## 공정 비교

1. 트래픽 입력 + **scenario seed**로 승객 스트림 하나 생성
2. **Replay**는 같은 스트림 재실행
3. **Compare all**은 브라우저에서 headless로 모든 파킹 전략을 일괄 실행
4. 다른 세상을 보고 싶을 때만 seed / New

## 질문

‘배치’는 **빈 차를 어느 층에 대기시킬지**입니다. 도착이 같으면 로비 파킹 vs stay/spread 차이가 avg wait·empty travel에 바로 드러납니다.

## Insight: 파킹이 먹히는 때

유휴 구간이 길수록 파킹이 중요하다. 한산·중간 부하에서는 Stay / Lobby / Mid / Spread / Demand가 대기·공차 이동을 가릅니다.

**항상 붐비는** 건물에서는 차가 거의 서지 않아 파킹 효과가 작아집니다. 그때는 **서비스 존 분할**(홀수/짝수층, 저층/고층 뱅크)로 정차 수와 왕복 시간을 줄이는 편이 맞습니다.

이 데모는 고정 시나리오에서 **파킹만** 비교합니다. Arrival rate를 올려 Compare all 하면 전략 간 차이가 줄어드는 경우가 많은데, 그건 “풀가동일 때는 파킹이 아니라 존”이라는 힌트입니다.

## 전략 카탈로그

**만능 1등 파킹은 없습니다.** 비행기 boarding(WilMA, back-to-front 등)처럼 제약이 바뀌면 순위가 바뀝니다.

| 전략 | 유휴 배치 | 전형적 적합 |
| --- | --- | --- |
| Stay | 마지막 층 | 반응형 베이스라인 |
| Lobby | 1층 | 상행 피크·귀가 |
| Mid | 중간층 | 절충 |
| Spread | 축 균등 홈 | 하행 피크·출근 |
| Demand | call heat | 적응 휴리스틱 |

이후 후보: arrival-probability parking, up-peak MDP 로비 대수, proactive standby, 포화 시 **서비스 존**.

## Batch 실험

데모의 **Batch N**(기본 100)은 현재 트래픽 노브로 seed `base … base+N−1`를 돌리고, 전략별 평균 대기·공차·승률과 CSV 로그를 만듭니다. 같은 base seed면 결과가 재현됩니다. “전 세계 최적”이 아니라 **이 레짐에서 어떤 베이스라인이 이기는지**를 보는 용도입니다.

## 건물 뷰

`Out | Fl | E1… | Hall` — 왼쪽은 내린 승객, 오른쪽은 홀 대기. 점·엘리베이터에 호버하면 경로/패널 정보가 뜹니다. 탑승은 collective **SCAN**(한 방향을 끝낸 뒤 반전).

## 트래픽 모델 (아파트 기본)

시드 + 트래픽 노브로 승객 OD를 한 번 만들고, Replay / Compare all에서 재사용합니다.

### Traffic period

**출발층 믹스**를 고릅니다.

| 시간대 | 출발 분포 (대략) | 이야기 |
| --- | --- | --- |
| Morning egress | 상부 ~90% / 로비 ~10% | 외출·출근 |
| Evening ingress | 로비 ~90% / 상부 ~10% | 귀가 |
| Midday / off-peak | 로비 ~45% / 상부 ~55% | 주간 혼재 |

목적지는 아래 아파트 규칙을 따릅니다.

### Arrival rate

틱마다 **최대 1명**이 등장할 확률(Bernoulli). 기본 **15%** ≈ 약 6.7틱에 1명. Poisson 도착의 이산 근사. 값을 올리면 동시 홀콜이 많아집니다.

### Interfloor trips

**상부 출발**일 때 목적지가 로비가 아니라 **다른 상부층**일 확률(기본 **10%**). 로비 출발은 항상 상부. 낮추면 로비 상하행 위주, 높이면 중간층 정차가 늘어납니다.

오피스형 임의 OD는 이후 분리.

## 컨트롤

| 컨트롤 | 역할 |
| --- | --- |
| Parking strategy | Stay / Lobby / Mid / Spread / Demand |
| Scenario seed | 고정 승객 스트림 |
| Traffic period | 출발층 믹스 (morning / evening / midday) |
| Arrival rate | 틱당 Bernoulli 도착 확률 |
| Interfloor % | 상부→상부 확률 (아니면 로비) |
| Door dwell | 층 정차 시간 |
| 건물 파라미터 | 층수, 대수, 정원, 목표 인원 |
