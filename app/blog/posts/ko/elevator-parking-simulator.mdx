**아파트**에서 유휴 엘리베이터는 어디에 대기해야 할까? 주거 통행이 대부분 로비와 세대 층 사이일 때, 파킹(대기 배치) 전략을 비교하고 승객 대기시간과 빈 차 이동 거리를 측정합니다.

## 질문

여기서 ‘배치’는 샤프트 위치가 아니라 **빈 차를 어느 층으로 보내 대기시킬지**입니다. 아파트에서는 2층 이상 호출이 대개 1층(로비)행이고, 저녁 귀가 피크는 로비→세대가 많습니다. 로비 고정 파킹은 귀가에는 유리하고 출근 하행에는 불리할 수 있습니다.

## 트래픽 모델 (아파트 기본)

| 시간대 | 전형적 흐름 |
| --- | --- |
| Morning egress | 상부 → 로비 |
| Evening ingress | 로비 → 상부 |
| Midday / off-peak | 양방향 |

층간 이동(upper↔upper) 기본 **10%**, 슬라이더로 조절. 오피스형 임의 OD는 이후 building type으로 분리 예정.

## 비교할 수 있는 것

| 컨트롤 | 역할 |
| --- | --- |
| Parking strategy | Stay / Lobby / Mid / Spread / Demand |
| Traffic period | Morning / Evening / Midday |
| Interfloor % | 로비를 거치지 않는 주거층 통행 비중 |
| Door dwell | 층 정차 시간 |
| 건물 파라미터 | 층수, 대수, 정원, 도착률 |

## 지표

- **Avg / Max wait** — 홀 콜부터 탑승까지
- **Completed** — 목표 대비 완료 트립
- **Empty travel** — 승객 없이 이동한 층 거리
