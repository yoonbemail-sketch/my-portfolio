유휴 엘리베이터는 어디에 대기해야 할까? 피크 트래픽 패턴 아래에서 **파킹(대기 배치) 전략**을 비교하고, 승객 대기시간과 빈 차 이동 거리를 측정하는 틱 기반 시뮬레이터입니다.

## 질문

여기서 ‘배치’는 샤프트 공사 위치가 아니라, **빈 차를 어느 층으로 보내 대기시킬지**입니다. 출근(up-peak: 로비 → 상부)에서는 로비 파킹이 대기를 줄이는 경우가 많고, 퇴근(down-peak)에서는 같은 정책이 공차 이동만 늘리고 상부 홀을 비울 수 있습니다.

## 비교할 수 있는 것

| 컨트롤 | 역할 |
| --- | --- |
| Parking strategy | Stay / Lobby / Mid / Spread / Demand |
| Peak mode | Mixed / Up-peak / Down-peak / Lunch |
| 건물 파라미터 | 층수, 대수, 정원, 도착률 |

## 지표

- **Avg / Max wait** — 홀 콜부터 탑승까지
- **Completed** — 목표 대비 완료 트립
- **Empty travel** — 승객 없이 이동한 층 거리 (파킹 비용)

## 동작

틱마다: 피크 모드로 OD 승객 생성 → 가능한 가까운 차 배정 → 이동/문 개방/승하차 → 유휴면 선택한 파킹 정책 적용. UI는 boarding-sim 패턴(전략 드롭다운, 슬라이더, Start/Pause/Reset, 대시보드)을 따릅니다.
