Kream 스니커즈 리셀 시장의 가격 신호와 사이즈·모델별 거래 패턴을 분석한 Operations Analyst 산출물입니다. 원천 거래 데이터를 안정적으로 적재하고, 분석용 모델로 정규화한 뒤 의사결정용 리포트로 연결하는 end-to-end 흐름에 초점을 둡니다.

소스 코드는 private로 유지합니다. 아래는 설계와 분석 관점의 요약입니다.

## Problem

리셀 의사결정에는 “지금 이 모델·사이즈가 얼마에, 얼마나 자주 거래되는지”가 필요합니다. 화면에서 보이는 최근 몇 건만으로는 시즌성, 사이즈 프리미엄, 배송 유형별 가격 차이를 보기 어렵습니다.

필요한 것:

1. 모델·사이즈 단위의 장기 거래 이력
2. 재수집·중단 후에도 이어서 적재할 수 있는 파이프라인
3. Power BI에서 슬라이스할 수 있는 분석용 fact / dimension 구조

## Pipeline overview

```text
Product page (model / size metadata)
        │
        ▼
Trade history collection (per size)
        │
        ▼
CSV per model · size  (+ resume / merge)
        │
        ▼
Validate · normalize dates · build sales fact
        │
        ▼
Star schema in Power BI
        │
        ▼
Dashboard (price · volume · seasonality)
```

수집은 Playwright 기반으로 브라우저 세션에 연결해 모델 번호·사이즈별 거래 행(사이즈, 가격, 날짜, 배송 유형)을 저장합니다. 배치 큐로 여러 SKU를 순차 처리하고, 사이즈별 파일을 병합한 뒤 Power BI용 fact 테이블로 합칩니다.

## Data quality rules

모델에 넣기 전 적용하는 규칙:

| Rule | Why |
| --- | --- |
| Size prefix validation | 스크롤 중 다른 사이즈 행이 섞이지 않도록 검증 |
| Completion ratio (≥ 90%) | 기대 거래량 대비 충분히 모였는지 판정 |
| Relative date → absolute | `3시간 전` / `2일 전` 등을 `YY/MM/DD`로 정규화 |
| Dedup on merge / update | 재수집 시 중복 거래 제거, 신규분만 append |
| Master product cache | `sneakers_info`에 브랜드·사이즈·발매일·정가를 캐시해 반복 분석 비용 절감 |

## Data modeling (star schema)

- **Fact** — `fact_transactions`: 완료된 리셀 거래 1건당 1행 (price, size, date, delivery type, model FK)
- **Dimensions** — `dim_product` (model no, name, brand, release date, retail price), `dim_size`, `dim_date`, `dim_delivery`
- **Grain** — 거래 1건
- **Relationships** — dimension → fact one-to-many; bidirectional filter는 필요한 경우만

```text
dim_product ──┐
dim_size    ──┼──► fact_transactions
dim_date    ──┤
dim_delivery──┘
```

## DAX notes

- dimension 속성을 복제하는 calculated column보다 **relationship** 우선
- 필터 컨텍스트가 동적으로 유지되어야 하면 로직을 **measures**에 둠
- 동일 filter context 반복을 피하기 위해 **VAR** 사용

```dax
Median Sale Price =
MEDIAN ( fact_transactions[price] )

Resale Premium % =
DIVIDE (
    [Median Sale Price] - SELECTEDVALUE ( dim_product[retail_price] ),
    SELECTEDVALUE ( dim_product[retail_price] )
)
```

| Layer | Tools |

## Results

분석용으로 모델·사이즈 단위 거래 이력을 적재하고, 병합·검증 후 Power BI fact로 연결하는 흐름을 구축했습니다. 대시보드 embed와 브랜드·시즌별 insight 수치는 게시 URL과 표본 SKU 확정 후 이 페이지에 갱신합니다.
